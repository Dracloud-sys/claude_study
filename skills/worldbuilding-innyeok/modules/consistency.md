# Module: Consistency — 일관성 검토 및 피드백

이 모듈은 새로 작성된 설정, 장면, 캐릭터 행동이 **인역 세계관의 기존 법칙과 충돌하지 않는지** 검토한다.

---

## 언제 이 모듈을 쓰는가

- 새 설정을 추가한 후 기존 세계관과 충돌 여부를 확인할 때
- 소설·게임 시나리오의 특정 장면이 레벨 체계나 영기 법칙에 맞는지 확인할 때
- 캐릭터의 능력치·행동이 설정상 가능한지 검증할 때
- 복잡한 설정들 사이의 논리적 연결을 점검할 때

---

## 검토 절차

### Step 1: 입력 분류

검토 대상이 무엇인지 먼저 분류:

| 분류 | 예시 |
|---|---|
| 설정 추가 | 새로운 세력, 기술, 장소, 규칙 |
| 캐릭터 행동 | 특정 레벨 캐릭터의 능력 사용 |
| 사건/플롯 | 특정 사건의 인과관계 및 파급효과 |
| 시스템 확장 | 기존 레벨/영기 체계의 변형 시도 |

### Step 2: 핵심 법칙 대조

아래 항목을 순서대로 점검:

#### 영기 법칙 체크
- [ ] 자동화·자율 판단이 불가능한 시스템이 등장하는가? → 영문 구조물의 한계 위반
- [ ] 영기 없이 영기 효과가 발생하는가? → 영기 공급원 명시 필요
- [ ] 의식 수준 없이 높은 영기 운용 효율이 묘사되는가? → 모순

#### 레벨 체크
- [ ] Lv.3 이하 캐릭터가 외부 세계에서 생존하는가? → 불가 (설정상 즉사에 가까움)
- [ ] Lv.3 이하 캐릭터가 사망 후 부활하는가? → 불가 (영체 미잔존)
- [ ] Lv.6 캐릭터가 인역 내에서 아무 문제 없이 존재하는가? → 인역 수용 한계 초과 위반
- [ ] 세 축(영기·육체·의식) 중 하나만 극도로 높고 레벨이 높게 책정되는가? → 모순

#### 스케일 체크
- [ ] 캐릭터의 행동이 레벨 대비 너무 강하거나 약하게 묘사되는가?
- [ ] 영문 구조물의 기능이 제작자 레벨보다 높은 등급을 요구하는가?

#### 인역 구조 체크
- [ ] 인역 내에 외부 세계 수준의 영기 밀도가 발생하는가? → 인역 붕괴 수준의 사건이어야 함
- [ ] 차원 경계가 설명 없이 무력화되는가?

### Step 3: 오류 분류 및 출력

발견된 문제는 다음 세 등급으로 분류:

| 등급 | 의미 | 권장 처리 |
|---|---|---|
| 🔴 치명적 모순 | 핵심 법칙을 직접 위반. 세계관 논리 붕괴 | 반드시 수정 또는 명시적 예외 근거 필요 |
| 🟡 주의 필요 | 법칙과 긴장 관계에 있음. 해석에 따라 가능 | 근거 보강 또는 제한 조건 추가 권장 |
| 🟢 문제 없음 | 기존 법칙 내에서 정합적 | 확인 완료 |

---

## 출력 형식

```
[검토 대상 요약]
검토 결과: 🔴 치명적 모순 / 🟡 주의 필요 / 🟢 문제 없음

발견된 문제:
1. [문제 항목] — [위반 법칙] — [수정 제안]
2. ...

수정 방향 제안:
- ...

수정 후 재검토가 필요한 부분:
- ...
```

## 자주 발생하는 오류 패턴

### "강한 적"을 만들려다 생기는 오류
- Lv.3 이하 마수가 Lv.4 인간을 압도 → 의식 수준 차이 고려 안 함
- 해결: 특정 속성 특화(단일 능력 우위)로 설명, 또는 레벨 상향

### "편의성" 설정 오류
- 사망한 Lv.3 캐릭터가 부활 → 영체 잔존 조건(Lv.4 이상) 위반
- 해결: 해당 캐릭터를 Lv.4로 상향하거나, 특수한 외부 개입으로 처리

### "AI처럼 동작하는 영문" 오류
- 상황을 스스로 판단하고 대응하는 영문 구조물 묘사
- 해결: 반드시 인간 운용자 개입 구조 추가, 또는 미리 설계된 분기 조건으로 한정

### "Lv.6의 평화로운 존재" 오류
- Lv.6 캐릭터가 인역 내에서 의도 없이 차원 균형에 영향
- 해결: 인역 수용 한계와 연동된 긴장 상태를 반드시 명시
