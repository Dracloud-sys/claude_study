# Module: Ecology — 생태계·마수·영기 지형 설계

이 모듈은 인역 세계관의 **자연 환경과 비인간 생명체**를 설계한다.
영기 지형, 마수 종류, 영기 침식종, 영원(靈源) 등을 구체화할 때 사용한다.

---

## 언제 이 모듈을 쓰는가

- 새로운 마수 종족이나 개체를 설계할 때
- 영기 지형·영원·영기 맥을 구체화할 때
- 영기 침식종의 특성과 위협 등급을 설정할 때
- 특정 지역의 생태계를 구성할 때
- 마수와 인간의 상호작용(자원화, 인류 자격, 전투 등)을 설계할 때

---

## 마수 설계 프레임워크

### 필수 정의 항목

```
[마수 이름]
1. 분류: 영기 감응종 / 영기 보유종 / 영기 침식종
2. 레벨 범위: (개체마다 다를 수 있음)
3. 의식 수준: 낮음 / 중간 / 인간에 준함
4. 영기 특화 속성: (특정 영기 유형에 특화된 경우)
5. 단일 특화 능력: 같은 레벨 인간을 상회하는 단일 능력 (있다면)
6. 서식 환경: 영원 근방 / 외부 세계 경계 / 일반 지역 등
7. 성장 메커니즘: 우연적 성장 / 의도적 수련 (의식 수준에 따라 결정)
8. 인간과의 관계: 적대 / 중립 / 공존 가능 / 인류 자격 사례 있음
9. 자원 가치 (침식종인 경우): 어떤 영기 소재를 제공하는가
```

### 레벨별 마수 설계 가이드

| 레벨 | 의식 수준 | 성장 방식 | 스토리 역할 |
|---|---|---|---|
| Lv.1~2 | 낮음 | 우연적 | 배경 생태계, 초보자 수련 대상 |
| Lv.3 | 낮~중간 | 우연적 | 중급 탐사 위협, 자원 대상 |
| Lv.4 | 중간~인간 준함 | 의도적 가능 | 개성 있는 개체, 인류 자격 후보 |
| Lv.5 | 인간에 준함 | 의도적 | 재해급, 또는 강력한 동맹 |

### 마수의 개체성 원칙

- 고레벨 마수는 **필연적으로 오랜 세월을 거친 개체** → 고유한 역사와 의식 보유
- 같은 종이라도 개체마다 경험·의식 수준 차이가 크다
- Lv.4 이상 마수는 언어·사고·감정을 인간과 유사하게 가질 수 있다

## 영기 침식종 설계 가이드

침식종은 외부 세계의 고밀도 영기에 노출되어 **의식이 붕괴·왜곡된** 변질 생물이다.

### 핵심 특성

- 영기 총량: 동급 일반 마수보다 **비정상적으로 높음**
- 의식: 붕괴 또는 극도로 왜곡 → 제어 불가, 예측 불가
- 인역 내 이변의 **징후**로 취급됨 (왜 침식종이 나타났는가?)

### 등급별 처우

| 레벨 | 처우 | 설계 시 포인트 |
|---|---|---|
| Lv.4 이하 | 자원 (영기 소재, 동력원, 영기 민감 자재) | 어떤 자원을 제공하는가? 채취 난이도는? |
| Lv.5 이상 | 재해 (토벌 대상) | 출현만으로도 지역 위기. Lv.4~5 팀 단위 대응 필요 |

### 침식종 등장의 의미

침식종 출현은 단순한 몬스터 이벤트가 아니라 **외부 세계와 인역 경계의 이상 신호**다. 설계 시:
- 왜 이 시기에, 이 장소에서 출현했는가?
- 차원 경계 안정성과 연결된 스토리 요인이 있는가?
- 침식종의 원래 종은 무엇이었는가? (비극적 서사 가능)

## 영기 지형 설계 가이드

### 영원(靈源) 등급

```
[영원 이름]
1. 영기 밀도 등급: 소형 / 중형 / 대형 / 극대형
2. 영기 속성: 일반 / 특화 속성 (특정 수련에 유리한 영기 유형)
3. 접근성: 공개 / 통제 구역 / 미발견
4. 관리 주체: 어떤 세력이 통제하는가?
5. 주변 생태계: 어떤 마수가 모여드는가?
6. 도시/시설 연계: 인근에 어떤 인프라가 형성되어 있는가?
7. 역사적 맥락: 이 영원과 관련된 사건·전설이 있는가?
```

### 영기 맥(靈氣脈) 패턴

인역 내 영기 맥은 균등하지 않다. 지형 설계 시 고려할 패턴:

| 패턴 | 특성 | 활용 |
|---|---|---|
| 단일 영원 집중형 | 한 지점에 영기가 집중 | 단일 도시 거점, 권력 집중 구조 |
| 맥선 분포형 | 여러 영원이 선형으로 연결 | 교역로·이동 경로와 겹치는 경우 多 |
| 분산 저밀도형 | 영원이 없거나 희박한 지역 | 개척지, 황무지, 저레벨 서식 구역 |
| 경계 근접형 | 외부 세계 경계 근방의 고밀도 지역 | 탐사 거점, 침식종 출몰, 고위험 수련지 |

## 생태계 구성 체크리스트

새 지역의 생태계를 설계할 때:

- [ ] 영원 유무 및 영기 밀도 수준 정의
- [ ] 영기 비의존종 · 감응종 · 보유종 각각의 존재 여부
- [ ] 지배적 마수 종 및 레벨 범위
- [ ] 침식종 출현 가능성 (차원 경계 근접 여부와 연동)
- [ ] 인간 정착 여부 및 영기공학 인프라 현황
- [ ] 해당 지역이 인역 전체 영기 순환에 미치는 역할
