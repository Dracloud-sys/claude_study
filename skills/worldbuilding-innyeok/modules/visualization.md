# Module: Visualization — 영상화 메타데이터 템플릿

이 모듈은 인역 세계관의 요소를 **영상·정적 이미지로 옮길 때 필요한 메타데이터**를 정의한다.
공통 베이스 슬롯 + 영역별 확장 슬롯의 2층 구조로 작동한다.

---

## 언제 이 모듈을 쓰는가

- 캐릭터·장면·도시·마수·세력 등을 시각화 산출물(애니/실사/시네마틱/일러스트/AI 이미지젠)로 변환할 때
- 새 설정을 만들 때 "영상화 가능성"을 미리 묶어두고 싶을 때
- AI 이미지젠 영문 프롬프트의 **시드 데이터**를 추출할 때 (실제 프롬프트 변환은 `imagegen` 스킬에 위임)
- 일러스트레이터·콘티 작가·감독에게 넘기는 비전 시트를 작성할 때
- 기존 요소의 시각 일관성이 흔들렸는지 점검할 때

---

## 작업 흐름

1. **베이스 템플릿** 채우기 — 영역과 무관하게 모든 요소가 공유하는 슬롯
2. **영역별 확장 템플릿** 채우기 — 캐릭터/장면/도시·건축/마수·생물/세력 중 해당하는 것만
3. **미디어 익스포트** — 정적 이미지용 / 영상용 슬롯을 분리해 채움
4. **일관성 가드** 통과 — 영기 법칙·레벨 시각 강도·장르 융합 원칙 점검
5. **출력 형식**으로 정리

`imagegen` 스킬 호출이 필요할 때는 `정적 이미지 시드` 블록만 떼어서 넘긴다. 본 모듈은 영문 프롬프트 변환 자체를 하지 않는다.

---

## 베이스 템플릿 (전 영역 공통)

```
[요소 이름 / 분류]

1. 시각 톤 시드
   - 사이버펑크 ↔ 선협 비율: 예) 70/30 — 도시 외형은 사펑, 영기 흐름은 선협
   - 메인 컬러 키: 3~5개 색 (16진 또는 명명. 예: 청록 영기, 짙은 강철, 주홍 경고등)
   - 머티리얼 키: 표면 질감 (예: 냉간 압연 강철 + 한지 + 유광 도자기)

2. 영기 시각 규약
   - 색: 영기 시각 색상 (인물·세력·영원별로 달라질 수 있음)
   - 입자: 미세 입자 / 안개 / 빛줄기 / 액화
   - 발광: 은은 / 명료 / 강렬 / 공간 왜곡
   - 흐름: 정적 / 호흡 동기 / 회로형 / 폭발형
   - 잔향: 동작 후 잔상 유무·길이

3. 레벨 시각 강도
   - Lv.0: 미발현 — 일상복, 영기 흔적 없음
   - Lv.1~2: 은은한 입자/발광, 의식적 사용 시에만 가시
   - Lv.3: 명료한 영기 가시화, 무기·도구에 잔상
   - Lv.4: 공간 자체가 반응 (바람·먼지·광량 변화)
   - Lv.5: 환경 왜곡 (중력감·시간감 변형, 주변 물질 반응)

4. 한 줄 무드
   - 5~12자 한국어 또는 한 문장 영문. 핵심 인상을 압축.

5. 일관성 가드
   - [ ] 영기는 의식 없이 자동 발광하지 않음 (장식적 자동 광량 금지)
   - [ ] 시각 강도가 설정 레벨과 일치
   - [ ] 사이버펑크와 선협 모티브가 한 프레임 안에 동시 등장
```

## 영역별 확장 슬롯

### 캐릭터

```
- 실루엣 키: 한 단어 — 예) 좁은 어깨·긴 코트·후드
- 의상 레이어: 안→밖 순서로 3~5개 레이어
- 시그니처 디테일: 포인트 1~3개 — 흉터·문신·악세서리·영문 자수 등
- 무기/장비: 이름 + 영기 발현 위치 + 휴대 방식
- 영기 발현 스타일: 어디서 / 어떻게 / 어떤 색
- 표정·자세 기본값: 정지 시 디폴트 무드
- 액션 스타일 (영상): 모션 무게감(경/중/육중), 안무 레퍼런스 (실존 무술 + 영기 동작 비율)
```

→ 캐릭터 설계 자체는 `characters/archetypes.md`, 수련 배경은 `world/cultivation.md` 참조.

### 장면(Scene)

```
- 공간 카테고리: 도시 상층 / 도시 하층 / 영원 근방 / 외부 세계 경계 / 외부 세계 내부 / 비공식 거점
- 시간대·기상: 영기 농도와 연동 — 예) 새벽 영기 침체, 야간 영기 활성
- 카메라 시작/종료: 와이드 → 클로즈업 등 한 줄 콘티
- 컷 호흡: 짧음(<2s) / 표준(2~4s) / 호흡(4~8s) / 롱테이크(8s+)
- 사운드 베드: 앰비언스 + 시그니처 사운드 — 예) 영기 도관 저주파 + 빗소리
- 색보정 방향: 예) 청록 시프트, 채도 낮춤, 하이라이트 보존
```

### 도시·건축

```
- 외관 등급: 1~5등급 영문 구조물 분류 (`world/architecture.md` 준수)
- 영기 도관 가시성: 노출 / 반매립 / 완전 매립
- 수직 계층 비율: 상층 X% / 중층 Y% / 하층 Z% (화면 내 차지 비율)
- 시그니처 실루엣: 도시를 한 컷에 담을 때 알아볼 수 있는 형태
- 야간/주간 톤: 두 톤이 어떻게 다른가 (영기등 vs 자연광)
- 인구 밀도 시각화: 군중 / 한산 / 폐허
```

→ 도시 정체성은 `world/cities.md`의 7대 도시 설정과 충돌하지 않도록.

### 마수·생물

```
- 분류 시각 규약:
  · 영기 감응종: 영기 흔적이 표면에 비침 (반사/잔향)
  · 영기 보유종: 영기 발광 위치가 신체에 고정 (눈·심장·뿔·꼬리 등)
  · 영기 침식종: 형태가 종 원형에서 왜곡, 영기 누출이 무질서
- 영기 발현 위치: 구체적 부위
- 크기 비교 기준: 성인 인간 기준 X배
- 동작 패턴: 포식자 / 회피형 / 정주 / 의식적 (의식 수준과 연동)
- 침식종일 경우: 원래 종 / 왜곡 정도 / 영기 누출 형태
```

→ 분류 규칙은 `world/ecology.md` 우선.

### 세력

```
- 컬러 코드: 메인 1색 + 액센트 1~2색
- 문장·로고 모티브: 한자 / 영문 / 추상 도형 중 어느 계열
- 복식 코드: 정복(공식) / 작업복(현장) / 사복(개인) 3종 슬롯
- 의례 영상 톤: 세력 공식 행사가 영상화될 때 — 예) 엄숙·기계적 / 의식적 침묵 / 군집 함성
- 시각 정체성 한 줄: 이 세력을 본 사람이 5초 안에 알아차릴 단서
```

→ 세력 본체 설정은 `world/factions.md` 참조.

## 미디어 익스포트

### 정적 이미지 시드 (AI 이미지젠 / 일러스트용)

```
- 주제: 1줄 (피사체 + 핵심 행동)
- 외형: 베이스 + 캐릭터 확장에서 추출
- 환경: 장면 확장 슬롯에서 추출
- 영기 표현: 영기 시각 규약에서 추출
- 분위기: 한 줄 무드 + 색보정 방향
- 스타일: 예) 그래픽 노블, 90s 애니메이션 셀, 시네마틱 포토리얼
- 카메라: 렌즈·앵글·거리
- 네거티브 시드: 피해야 할 요소 (예: 자동 발광, 서양 갑옷, 데포르메)
```

이 블록은 **그대로 `imagegen` 스킬에 넘겨** 영문 프롬프트로 변환한다.

### 영상 메타 (애니/실사/시네마틱)

```
- 카메라: 무브 (고정/팬/달리/핸드헬드/드론)
- 렌즈: 환산 화각 (예: 35mm 표준, 85mm 인물, 14mm 광각)
- 조명: 키 라이트 위치 + 영기 광원 비율 (자연광 X% / 영기광 Y%)
- 동작: 안무 레퍼런스 (실존 무술 + 영기 동작의 결합 비율)
- 사운드: 앰비언스 + SFX 시그니처 + 음악 스타일
- 길이: 단일 컷 / 시퀀스 / 시리즈
- 트랜지션: 컷·디졸브·매치컷·영기 잔상 트랜지션
```

---

## 영상 콘티 슬롯 (시퀀스 단위)

한 시퀀스 = **3~7비트가 표준**. 비트당 슬롯:

```
[비트 N]
- 컷 길이: (초)
- 카메라: 앵글 + 무브
- 동작: 피사체 액션
- 영기 변화: 어떤 시각 변화가 일어나는가
- 사운드: 이 비트의 시그니처 음향
- 트랜지션: 다음 비트로의 연결 방식
```

## 일관성 가드 (체크리스트)

영상화 메타데이터를 출력하기 전 통과 필수:

- [ ] 영기 자동 발광 금지 — 광원이 있다면 영기공학 장치 또는 의식 행사로 설명되는가?
- [ ] 레벨 시각 강도 일치 — Lv.1 캐릭터에 Lv.4급 환경 왜곡 광량을 부여하지 않았는가?
- [ ] 장르 융합 — 사이버펑크와 선협 모티브가 한 프레임 안에 동시 존재하는가? (영기공학 표면이 둘을 잇는 매개)
- [ ] 외부 세계 표현 — 외부 세계 장면이라면 인역과 명백히 다른 영기 밀도가 시각화되었는가?
- [ ] 세력·도시·마수의 기존 설정과 시각 충돌 없는가? (`world/factions.md` / `world/cities.md` / `world/ecology.md`)

## 출력 형식

```
[요소 이름 / 분류]

■ 시각 톤 시드
- 사펑↔선협 비율 / 컬러 키 / 머티리얼 키

■ 영기 시각
- 색 / 입자 / 발광 / 흐름 / 잔향

■ 레벨 시각 강도
- Lv.X (해당 등급 설명)

■ 한 줄 무드
- ...

■ 영역별 확장
- (해당 영역 슬롯만)

■ 정적 이미지 시드
- (imagegen 호출 입력 블록)

■ 영상 메타
- 카메라 / 렌즈 / 조명 / 동작 / 사운드 / 길이 / 트랜지션

■ 일관성 가드
- 자동 발광 / 레벨 강도 / 장르 융합 / 외부 세계 / 기존 설정 (각 ✔/✘)

■ 스토리 활용 포인트
- 이 시각 메타가 서사 어디에서 결정적으로 작동하는가
```
