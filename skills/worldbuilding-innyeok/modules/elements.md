# Module: Elements — 세력·정치·기술·이름 생성

이 모듈은 인역 세계관 내의 **구체적 요소들**을 생성하고 설계한다.
세력, 조직, 도시, 기술, 인물명, 술어 등을 인역의 톤과 논리에 맞게 만들 때 사용한다.

---

## 언제 이 모듈을 쓰는가

- 세력·문파·조직·국가를 설계할 때
- 도시 또는 지역의 정치·경제 구조를 구체화할 때
- 인물 이름, 기술 명칭, 조직명을 생성할 때
- 영기공학 장비·영문 구조물의 구체적 사양을 설계할 때
- 사이버펑크 요소(도시 빈부 격차, 언더그라운드, 기업 권력 등)를 인역에 통합할 때

---

## 세력 설계 프레임워크

### 필수 정의 항목

```
[세력명]
1. 핵심 이해관계: 이 세력이 지키려는 것 / 원하는 것
2. 레벨 구성: 주요 구성원의 레벨 분포 (예: Lv.2~3 다수, Lv.4 소수, Lv.5 1인)
3. 영기공학 역할: 이 세력이 인역 인프라에서 차지하는 위치
4. 외부 세계와의 관계: 탐사 참여 여부, 외부 세계에 대한 태도
5. 사회적 위치: 공식 기관 / 비공식 / 언더그라운드 / 초국가적
6. 내부 갈등 요인: 세력 내부의 균열 지점
7. 타 세력과의 관계: 동맹·경쟁·적대 구도
```

### 인역의 세력 유형 (참고 틀)

| 유형 | 특성 | 사이버펑크 대응 | 선협 대응 |
|---|---|---|---|
| 영기공학 대기업 | 영문 기술 독점, 인프라 통제 | 메가코프 | 대형 문파 |
| 국가 방위 기관 | Lv.4~5 보유, 외부 세계 탐사 공식 권한 | 군·정보국 | 관방 수련원 |
| 독립 탐사 조합 | Lv.3~4 중심, 외부 자원 밀거래 | 용병 길드 | 강호 문인 집단 |
| 영기 의술 집단 | 치료·육체 강화 서비스 독점 | 의료 기업 | 의선 문파 |
| 영기 침식종 연구 기관 | 침식종 자원화·통제 연구 | 바이오텍 | 이단 연구자 집단 |
| 인류 자격 옹호 단체 | 고레벨 마수 권리 운동 | NGO·활동가 집단 | 인수(人獸) 공존 사상 |
| 언더그라운드 술사 집단 | 비인가 영문 기술, 금지된 수련법 | 해커 집단 | 사도(邪道) 문파 |

## 이름 생성 가이드

### 인역의 언어 감각

인역 세계관의 명명 원칙:
- **한자어 기반**이되 현대적 감각으로 재조합 (선협 계통)
- **기술 용어**는 영기공학 어휘 체계를 따름 (영문·영기·도관·공명 등)
- **고유명사**는 한자 의미가 설정 내용을 암시하도록 설계 권장

### 인물 이름 생성 시 체크

- [ ] 레벨 및 역할이 이름의 어감과 어울리는가?
- [ ] 소속 세력의 문화가 이름에 반영되는가?
- [ ] 사이버펑크 도시 출신 vs 전통 수련 문파 출신의 어감 차이를 의도했는가?

### 기술·술식 명명 원칙

```
구조: [영기 작용 방식] + [대상/효과] + [형식 명칭]
예시:
- 영기 집속 타격술 → 영기(靈氣) + 집속(集束) + 격(擊) → "영집격(靈集擊)"
- 영문 방어막 장치 → 영문(靈紋) + 호위(護衛) + 진(陣) → "영문호위진(靈紋護衛陣)"
- 원거리 영기 공명 통신 → 영기(靈氣) + 공명(共鳴) + 부(符) → "영공명부(靈共鳴符)"
```

## 도시·지역 설계 가이드

인역의 도시는 **영원(靈源)을 중심으로 형성**된다. 도시 설계 시:

1. **영원 등급**: 해당 도시의 영원이 얼마나 강력한가? → 도시 규모·기술 수준 결정
2. **수직 구조** (사이버펑크 계층): 영기 인프라 접근성에 따른 빈부 격차
   - 상층: 고출력 영기 회로 접근, 고레벨 술사 거주
   - 하층: 영기 공급 불안정, Lv.0~1 밀집
3. **영기공학 인프라 현황**: 어떤 등급의 영문 구조물이 운영되고 있는가?
4. **외부 세계 접근성**: 외부 세계와의 경계 근접 여부 → 탐사 거점 여부
