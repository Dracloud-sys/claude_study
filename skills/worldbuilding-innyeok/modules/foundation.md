# Module: Foundation — 세계 법칙 및 기반 설계

이 모듈은 인역 세계관의 **근본 법칙과 구조**를 다룬다.
새로운 설정을 추가하거나 세계관의 핵심 원리를 확장할 때 사용한다.

---

## 언제 이 모듈을 쓰는가

- 영기 체계의 새로운 측면을 정의할 때
- 레벨 시스템에 예외 또는 변형 규칙을 추가할 때
- 인역과 외부 세계의 관계를 구체화할 때
- 세계관의 우주론적 질문(차원 경계의 기원, 영기의 근원 등)을 다룰 때
- 수련 체계의 구체적 방법론을 설계할 때

---

## 핵심 법칙 체크리스트

새 설정을 추가하기 전, 아래 법칙과 충돌하지 않는지 확인:

### 영기 법칙
- [ ] 영기는 의식에 의해 움직인다 — 의식 없는 완전 자동화는 불가
- [ ] 영기는 축적량 상한이 존재하며, 육체 수준이 받쳐줘야 한다
- [ ] 영문 구조물은 설계된 패턴 내에서만 작동한다
- [ ] 외부 세계는 고밀도 영기 공간이며, 인역과 성질이 다르다

### 레벨 법칙
- [ ] 레벨은 영기 축적량·육체 수준·의식 수준 세 축의 균형으로 결정된다
- [ ] Lv.4 미만은 외부 세계 탐사 불가 (의식 수준 미달)
- [ ] Lv.5는 인류 종의 현실적 상한. Lv.6은 질적 전환이지 양적 강화가 아니다
- [ ] Lv.4 이상은 사후 영체 잔존, 부활 가능

### 인역 구조 법칙
- [ ] 인역의 수용 한계는 영기 총량 × 차원 경계 안정성
- [ ] Lv.6 개체는 역사상 전례 없음 — 인역이 아직 수용 불가
- [ ] 인역은 저영기 안정 구역이다

## 수련 체계 설계 가이드

수련 방법을 새로 정의할 때 반드시 포함해야 할 요소:

1. **세 축 중 어느 축을 주로 강화하는가?**
   - 영기 축적량 중심 (흡수·저장 수련)
   - 육체 수준 중심 (신체 단련·영기 친화도)
   - 의식 수준 중심 (명상·정신 수련·외부 세계 경험)

2. **속도와 위험성의 균형**
   - 영기 과부하 시 신체 붕괴 가능성
   - 의식 수련 부족 시 영기 폭주 위험

3. **사이버펑크 요소와의 접점**
   - 영기공학 보조 장비를 통한 수련 가속
   - 영문 구조물을 활용한 영기 흡수 장치
   - 영기 의술을 통한 육체 수준 단기 강화

4. **인역 내 수련 vs 외부 세계 수련**
   - 인역: 안전하나 영기 밀도 낮아 성장 느림
   - 외부 세계: 고위험 고보상. Lv.4 이상 전용

---

## 차원 경계 및 우주론 확장 시 유의사항

- 차원 경계의 기원은 **현재 문명 수준에서 미규명** — 이 불확실성을 유지할 것
- 경계가 인공적으로 만들어진 것이라면, 누가 만들었는지는 최고 레벨 미스터리로 보존 권장
- 외부 세계는 단일한 공간이 아닐 수 있음 — 복수의 외부 층위 존재 가능 (단, 설정 추가 시 명시적 정의 필요)
