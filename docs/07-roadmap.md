# 07. 4주 실행 로드맵

읽고 끝내면 남는 게 없다. **주당 2~3시간**으로 실제 환경을 구축하는 순서.

---

## 1주차 — 기반 다지기 (로컬)

- [ ] 이 저장소에 `CLAUDE.md` 작성 (빌드/테스트 명령, 금지사항, 커밋 규칙). **1페이지 넘기지 말 것**
- [ ] 로컬 CLI에서 읽기 전용 작업만 해보기: 코드 설명, 조사, 리뷰 의견
- [ ] `claude --permission-mode plan`으로 계획만 세우는 세션 경험
- [ ] 자주 반복한 프롬프트 3개를 메모 → 2주차 스킬 후보

**검증**: "이 저장소 규칙에 맞게" 요청했을 때 컨벤션을 지키는가?

---

## 2주차 — 자산화 + 클라우드 왕복

- [ ] 반복 프롬프트 1개를 `.claude/skills/<name>/SKILL.md`로 변환
- [ ] `claude --cloud "..."`로 작업 하나 클라우드에 위임 → `/tasks`로 확인
- [ ] `claude --teleport`로 결과를 로컬로 회수해보기
- [ ] 클라우드 환경의 네트워크 정책·셋업 스크립트 확인/설정
- [ ] 모바일 앱에서 세션 열어보기

**검증**: 노트북을 닫았다가 열었을 때 클라우드 작업이 진행돼 있는가?

---

## 3주차 — GitHub 자동화

- [ ] 로컬에서 `/install-github-app` → `@claude` 멘션 워크플로 설치
- [ ] PR 자동 코드리뷰 워크플로 추가 (`code-review` 스킬)
- [ ] PR 하나에 Auto-fix 켜서 CI 실패 자동 수정 관찰
- [ ] 워크플로에 `--max-turns`, timeout, concurrency 상한 설정

**검증**: 이슈에 `@claude`로 요청 → PR이 열리는가? 리뷰 지적의 오탐률은?

---

## 4주차 — 무인 예약 운용

- [ ] Routine 1: 야간 의존성/보안 감사 → PR (매일 03:00)
- [ ] Routine 2: 아침 브리핑 → 이슈 또는 슬랙 (평일 08:30)
- [ ] Routine 3: 월 1회 `docs/01-models.md` 최신화 PR (매월 1일)
- [ ] 각 루틴에서 **커넥터 최소화**, 결과를 밖으로 밀어내는 지시 포함
- [ ] `/schedule list`로 목록 확인, 1주 뒤 실행 이력 점검

**검증**: 자고 일어났을 때 PR/브리핑이 와 있는가? 실패한 실행은 어떻게 알게 되는가?

---

## 5주차 이후 — 측정과 개선

- [ ] 자체 eval 세트 10건 구축 (해결된 이슈 기반, 기계 판정 기준)
- [ ] 현재 구성으로 베이스라인 측정: 통과율 / 토큰 / 시간
- [ ] 모델 하향 실험: 어떤 작업을 더 싼 모델로 내려도 되는가?
- [ ] 지표 추적: AI PR 무수정 머지 비율, 롤백률, 월 토큰

---

## 실패 신호와 대응

| 증상 | 진짜 원인 | 조치 |
|---|---|---|
| AI PR을 매번 크게 고쳐야 함 | 컨텍스트/스펙 부족 | `CLAUDE.md` 보강, 작업 단위 축소 |
| AI 리뷰를 아무도 안 봄 | 오탐 과다 | 리뷰 스킬을 "확신 있는 것만"으로 튜닝 |
| 루틴이 조용히 아무것도 안 함 | 프롬프트가 자족적이지 않거나 네트워크 차단 | 트랜스크립트 확인, 결과 보고 지시 추가 |
| 토큰 비용 급증 | 무한 재시도, 컨텍스트 비대 | turn 상한, 압축, 모델 하향 |
| 세션 간 맥락 유실 | 상태를 대화에 의존 | 계획·결정을 파일로 커밋 |
