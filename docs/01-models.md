# 01. 최신 모델 지형도와 선택 기준

> 기준일 2026-09-05. 모델 라인업은 6~12주 단위로 바뀐다. **버전 숫자를 외우지 말고 "고르는 규칙"을 외울 것.**

## 1. 지금 시장 구조 (3계층)

### 계층 A — 프론티어 (API/구독, 최고 성능)

| 계열 | 대표 모델(2026-09 기준) | 강점 |
|---|---|---|
| Anthropic Claude | Opus 5 / Sonnet 5 / Fable 5.1, Haiku 4.5 | 장시간 에이전트 코딩, 도구 사용, 긴 문맥 유지, 글쓰기 |
| OpenAI GPT | GPT-5.6 계열 | 범용성, 생태계·서드파티 통합 폭 |
| Google Gemini | Gemini 3.x Pro/Flash | 가격 대비 추론 성능, 초장문·멀티모달 |
| xAI Grok | Grok 4.6 | 실시간 정보 결합 |

> 실무적 결론: **상위 모델 간 "지능" 격차는 이미 작다.** 선택 기준은 성능이 아니라
> ① 내가 쓰는 하네스(Claude Code / IDE / SDK)와의 결합도, ② 단가, ③ 데이터 정책이다.

### 계층 B — 오픈웨이트 (자체 서버 / 온프렘)
- **DeepSeek V4** 계열: 코딩·추론 최상위권, 관대한 라이선스, 초장문 컨텍스트
- **Qwen3.x** 계열: 크기 라인업이 촘촘해 "내 GPU에 맞는 크기"를 고르기 쉬움, 다국어(한국어 포함) 양호
- **GLM / Kimi / Nemotron / gpt-oss**: 코딩·추론 특화 대안

### 계층 C — 로컬 소형 (노트북/워크스테이션)
- 32GB RAM 급: 30B급 MoE 모델 1개가 현실적 상한
- 128GB 급: 100B급 또는 코더 특화 모델까지
- 실행 도구: Ollama / llama.cpp / LM Studio / vLLM(서버)

## 2. 모델 선택 규칙 (외울 것은 이것)

```
민감 데이터가 외부로 나가면 안 되는가?
├─ 예 → 계층 B/C (온프렘·로컬). 성능 손해는 감수.
└─ 아니오
   ├─ 작업이 "설계/디버깅/멀티스텝 에이전트"인가?
   │   └─ 예 → 계층 A 최상위(Opus 5급). 토큰 더 써도 총비용 싸다.
   └─ 작업이 "분류/요약/변환 대량 반복"인가?
       └─ 예 → 중소형(Haiku/Flash급) 또는 오픈웨이트 자체 호스팅.
```

**핵심 원칙 3가지**
1. **비싼 모델은 "생각"에, 싼 모델은 "노동"에.** 난이도가 아니라 *실패 시 비용*으로 나눈다. 잘못된 아키텍처 결정은 100만원, 잘못된 요약은 100원.
2. **모델을 바꾸기 쉽게 짜라.** 모델 ID를 코드에 박지 말고 설정/환경변수로. 3개월 뒤 반드시 바뀐다.
3. **벤치마크는 스크리닝용, 채택 결정은 자체 eval로.** SWE-bench 점수 2%p 차이보다 "내 코드베이스 5개 이슈를 누가 더 잘 고치나"가 100배 중요하다.

## 3. 비용 구조 이해

| 요소 | 설명 | 절감 레버 |
|---|---|---|
| Input 토큰 | 보낸 컨텍스트 | 컨텍스트 다이어트, **프롬프트 캐싱**(반복 시스템 프롬프트/문서는 캐시 히트로 대폭 절감) |
| Output 토큰 | 생성 길이 | "설명 말고 diff만" 같은 출력 형식 지정 |
| 사고(thinking) 토큰 | 추론 예산 | 쉬운 작업엔 effort 낮춤 |
| 재시도 | 실패한 턴 | 지시 명확화, `--max-turns` 상한 |

- **구독(Claude Pro/Max) vs API 종량제**: 개인이 대화형으로 쓰면 구독이 압도적으로 싸다. 자동화·다중 사용자·CI에 붙이면 API 키(또는 조직 크레딧)가 관리상 유리하다.
- 자동화를 붙일 때는 **반드시 상한선**(turn 제한, 타임아웃, 동시 실행 제한)을 건다. 무한 루프 한 번이 한 달 예산을 태운다.

## 4. 갱신 루틴

이 문서는 오래된다. 분기마다 아래를 다시 확인:
1. 각 벤더 모델 페이지의 현행 모델 ID와 단가
2. 내 자체 eval 세트를 새 모델로 재실행 → 승격 여부 결정
3. 로컬 모델은 "내 하드웨어에서 도는 최대 크기"가 바뀌었는지
